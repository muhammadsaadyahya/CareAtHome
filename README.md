# CareAtHome

An Android application built with **Kotlin** designed to provide healthcare support and management services at home.

## Overview

CareAtHome is a mobile application that leverages modern Android development practices and Google Cloud technologies to deliver healthcare solutions directly to users' homes. The app integrates Firebase for authentication and real-time data management, along with Google's Generative AI for intelligent health insights.

## Features

- **User Authentication**: Secure Firebase authentication for user management
- **Real-time Data Sync**: Firebase Firestore for instant data synchronization
- **AI-Powered Insights**: Integration with Google Generative AI for health recommendations
- **Real-time Database**: Firebase Realtime Database for critical health data
- **Analytics**: Built-in Firebase Analytics for tracking user engagement
- **Modern UI**: Material Design components with responsive layouts
- **View Binding**: Type-safe view access with Data Binding support

## Tech Stack

### Languages & Frameworks
- **Kotlin** - Primary programming language (100% of codebase)
- **Android SDK** - Target SDK: 35, Min SDK: 25
- **Java 11** - JVM compatibility

### Key Dependencies
- **Firebase**: 
  - Authentication
  - Cloud Firestore
  - Realtime Database
  - Analytics
- **Google Generative AI** - AI-powered features
- **Material Design** - UI components
- **AndroidX**:
  - AppCompat
  - ConstraintLayout
  - LiveData & ViewModel (MVVM architecture)
  - SwipeRefreshLayout
- **Testing**: JUnit, Espresso (Android Instrumentation Testing)
